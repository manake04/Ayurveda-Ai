# Corpus sources

_Generated by `python scripts/ingest.py sources --markdown` — do not edit by hand._

The corpus (`corpus/india.json`, `corpus/international.json`) is assembled from the open,
authoritative primary sources below. `scaffold` can fetch from the ones marked
**automatable**; the others must be transcribed by hand from the primary text.

## India

### `india-code` — India Code (Ministry of Law & Justice)

- **Homepage:** https://www.indiacode.nic.in/
- **`source_name`:** `India Code`  (+ ` – <instrument>` suffix)
- **Fetch:** html (**automatable**)
- **Locator:** A India Code handle, e.g. '123456789/1388' (the Patents Act, 1970), taken from the handle URL of the Act's landing page. A full indiacode.nic.in URL also works.
- **Scaffold:** `python scripts/ingest.py scaffold --source india-code --locator 123456789/1388 --regime <regime> --id <slug>`

### `egazette` — e-Gazette of India (Department of Publication)

- **Homepage:** https://egazette.gov.in/
- **`source_name`:** `e-Gazette of India`  (+ ` – <instrument>` suffix)
- **Fetch:** pdf (**automatable**)
- **Locator:** The full https://egazette.gov.in/.../<file>.pdf URL of the gazette notification.
- **Notes:** Notifications are PDFs; excerpt verification needs the optional `pypdf` extra.
- **Scaffold:** `python scripts/ingest.py scaffold --source egazette --locator <locator-or-url> --regime <regime> --id <slug>`

### `inpass` — Indian Patent Office public patent search (InPASS)

- **Homepage:** https://ipindiaservices.gov.in/publicsearch
- **`source_name`:** `Indian Patent Office – InPASS public search`
- **Fetch:** not_automatable (**not automatable**)
- **Locator:** (not automatable)
- **Notes:** InPASS and the GI / Trade Marks / Designs registers are captcha-gated search front-ends with no public API — they cannot be scraped honestly. Look a record up by hand and add the entry with `scaffold --source india-code` or a hand-written entry.
